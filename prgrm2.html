What is HTML?

HTML is the standard markup language used to create web pages. HTML stands for HyperText Markup Language. It describes the structure of a web page.

  • Head
  • Body
  • Title

HTML is easy to learn. You will enjoy it! HTML is used for creating web pages.
HTML describes the structure of a web page.
HTML elements tell the browser how to display content.
